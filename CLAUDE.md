# CLAUDE.md — для наступних автономних сесій

## Що це

`neurica.net` — публічна експериментальна поверхня EONYX. Astro 7,
TypeScript strict, content collections + Zod, без Tailwind, без
UI-фреймворків, без бекенду. Деталі — `docs/00-what-neurica-is.md` і
`docs/04-architecture.md`.

## Межа, яку не можна розмити

> Жива лабораторія, але ніколи не другий production-контур.

Це не побажання — це `[5.1]` у `src/content.config.ts`
(`workSchema.superRefine()`). Якщо об'єкт має `data_mode:
LIVE_BUSINESS`, або `context: ALTACO` разом із `status: LIVE` —
збірка падає. **Це правило не обходять.** Якщо здається, що конкретний
випадок вимагає винятку — випадок хибний, не правило: щось, що
вимагає `LIVE`-бізнес-даних на цьому сайті, належить власному
контуру, не Neurica.

Не пом'якшувати повідомлення 5.1 до generic zod-помилки — воно навмисно
пояснює *чому*, а не просто називає поле.

## Порядок кроків

Публікація об'єкта: **03 → 05** (`docs/03-publishing.md` →
`docs/03a-localisation.md` для мовної частини). Не додавати об'єкт без
обох `uk.md`/`en.md` — 5.7 однаково зупинить збірку, простіше зробити
одразу правильно.

Дизайн головної, верстка стрічки/карток/hero — окремий крок ("05" у
сенсі "наступна сесія", не файл `docs/05-decisions.md`). Каркас цієї
сесії структурний, невідформатований: мінімальний CSS для
читабельності — так, візуальні рішення — ні.
