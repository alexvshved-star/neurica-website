# CLAUDE.md — для наступних автономних сесій

## Що це

`neurica.net` — публічна експериментальна поверхня EONYX. Astro 7,
TypeScript strict, content collections + Zod, без Tailwind, без
UI-фреймворків, без бекенду в поточній реалізації. Пілот може
додати потрібний рантайм та авторизацію за docs/08-altaco-pilot.md. Деталі — `docs/00-what-neurica-is.md` і
`docs/04-architecture.md`.

## Робочі пілоти — рішення власника 06.09.2026

Neurica може нести реальне бізнес-навантаження в погодженому обсязі.
Перший пілот — каталог ALTACO, клієнтські КП і прайси на період
розробки ALTACO Platform. Канон: `docs/08-altaco-pilot.md`.
Реальні товарні дані дозволені; публічні та внутрішні дані й функції
мають різний доступ. Єдине джерело, дата даних і переносимість модулів
обов'язкові.

Стара абсолютна заборона комерційного використання скасована.
У коді 5.1 наразі ще відхиляє LIVE_BUSINESS і ALTACO + LIVE:
це відома незавершена міграція, а не чинна продуктова заборона.
Під час реалізації замінити її явними перевірками пілота, одночасно
узгодивши схему, RuntimeNotice, фікстури й тести. Не вимикати перевірки
мовчки, не маскувати реальні операції під SYNTHETIC або STATIC.
До реалізації залишити статус каталогу STATIC.

5.7 (обидві мови) та 5.8 (жодних плейсхолдерів endpoint/build_ref)
зберігаються. Публічний опис має відповідати фактично реалізованим функціям.

## Порядок кроків

Публікація об'єкта: **03 → 05** (`docs/03-publishing.md` →
`docs/03a-localisation.md` для мовної частини). Не додавати об'єкт без
обох `uk.md`/`en.md` — 5.7 однаково зупинить збірку, простіше зробити
одразу правильно.

Інформаційна архітектура (ролі сторінок, шаблони об'єкта, масштаб
картки) закрита — `docs/06-information-architecture.md`. Дизайн
головної, верстка стрічки/карток/hero лишається окремим кроком ("05"
у сенсі "наступна сесія", не файл `docs/05-decisions.md`). Структура
цієї сесії невідформатована: мінімальний CSS для читабельності —
так, візуальні рішення — ні.
