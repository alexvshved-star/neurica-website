# Журнал рішень

| # | Рішення | Причина |
|---|---|---|
| 001 | Домен і назву збережено | етимологія не критична; перегляд через 6–12 міс. |
| 002 | Snapshot, не живі дані ALTACO | static не має шару, де приховати поля |
| 003 | Демо вбудовується артефактом, не підключається | артефакт не розходиться з джерелом і не падає разом |
| 004 | Дві осі: type і status | одна не виражає «CASE + FROZEN» |
| 005 | `/index-en` і `/en` → 301 → `/en/`, на `/` редиректу немає | старий сайт — одна сторінка у двох мовах, підсторінок продукту не було; 410 застосовувати нема до чого |
| 006 | Без Tailwind | дублює шар токенів |
| 007 | Структурні поля спільні для мов | дубльовані розходяться, 5.1 стає вибірковим |
| 008 | Таксономія не перекладається | технічний регістр, mono-трактування |
| 009 | Слаг спільний, різниця лише в префіксі | стабільні URL, тривіальний перемикач |
| 010 | uk в корені, en під `/en/` | основна аудиторія українська |
| 011 | Форм на каркасі немає | заявка про співпрацю — поведінка eonyx.net; рішення відкладене |
| 012 | `src/content.config.ts`, не `src/content/config.ts` | Astro 7 видалив legacy-розташування файлу конфігурації колекцій |
| 013 | Кастомний loader замість стандартного glob-loader'а | об'єкт складається з 3 файлів (index.yaml + uk.md + en.md), потрібна одна крос-файлова валідація на slug |
| 014 | `/work` без інтерактивного UI фільтрів на цьому кроці | NON-GOALS сесії забороняє форми й поля вводу; фільтрація за type/status — верстка кроку 05 |
| 015 | Семантичні бренд-токени (`--brand-black/navy/cyan/red`) замість шкали navy | брендбук задає чотири окремі кольори, не градації |
| 016 | Контраст `--brand-black` / `--brand-navy` = 1.07:1; у CHROMATIC і ORGANIC `card-border: none` | картки не матимуть візуального відділення від фону; перевірити на кроці 05 |
| 017 | `--weight-body: 400` (Regular) підтверджено, не 300 (Light) | відрендерено обома мовами на `--color-bg` (`/dev/type`, Playwright): Light помітно тонший і втрачає контраст на темному фоні, Regular лишається суцільним і комфортним для читання. Montserrat Regular не в переліку брендбука (Light/SemiBold/Bold/Black), але практична читабельність важливіша за формальну відповідність переліку — Light для абзацного тексту на такому фоні гірший варіант, це видно, а не виводиться |
| 018 | `/archive` — тільки `ARCHIVE`, `FROZEN` лишається в `/work` | попередній бриф ставив `FROZEN` в архів, що суперечить 5.3: «сторінка живе далі» означає лишитися на видноті, не переїхати в архів |
| 019 | `published` (ISO-дата) замінює `year` як структурне поле | `year` не задає порядку — два об'єкти того самого року нічим не впорядковуються; `year` для показу тепер виводиться з `published` |
| 020 | `/work/[type]` зарезервовано, не реалізовано в v1 | при п'яти об'єктах фільтр — UI без задачі; статичні `/work/[type]` індексуються й не потребують полів вводу, коли з'являться |
| 021 | `feature` — єдине ручне поле масштабу картки, максимум 3 | масштаб (large/medium/small) виводиться з feature + type/status; понад 3 featured — warning на збірці, не fail |
| 022 | Правило 5.8 — заборона плейсхолдерів у `endpoint`/`build_ref` | `altaco-catalog` вів на неіснуючий домен; RuntimeNotice захищає від "дані непевні", не від "посилання мертве" |
| 023 | Перевірка доступності endpoint — окремий не блокуючий крок CI | зовнішній збій не повинен зупиняти збірку сайту, але має лишатись видимим до першого відвідувача |
| 024 | `media[]`: `{id,src}` структурно, `{alt,caption}` локалізовано за тим самим id | те саме розділення, що й для решти полів моделі; кожен id обов'язковий в обох мовах, як 5.7 для перекладів |
| 025 | `h1` і `.type-display` розділені: h1 = `--type-h1`/weight-strong, display = `--type-display`/weight-display, лише для знака `NEURICA` в hero | до цього жоден з двох не мав `font-size` узагалі й падав на дефолт браузера; display 900 на заголовку сторінки був би занадто важким |
| 026 | Компоненти сторінок використовують `var(--section-gap)`, не `var(--section-gap-mobile)` | `--section-gap` вже адаптивний (сам перемикається на mobile-значення в tokens.css); хардкод mobile-значення напряму означав, що desktop отримував той самий тісний відступ, що й mobile |
| 027 | `--tracking-label: 0.14em` лишається спільним для uk/en, без окремого правила для кирилиці | перевірено реальним рендером (`/dev/type`, Playwright): кирилична все-капс мітка не розсипається при 0.14em; production сьогодні кирилицю крізь `.meta` й так не жене (таксономія завжди англійська, рішення 008) |
